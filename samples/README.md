# Demo samples

Generated by `packages/loggen` and not committed. Regenerate with:

```bash
npm run loggen -- --seed 42 --days 3 --out samples      # about 200,000 lines, about 1 s
npm run loggen -- --seed 42 --small --out samples       # a few minutes around each scenario
```

The same seed always produces byte-identical files.

Layout:

| File | Content |
| --- | --- |
| `samples/<host>/auth.log` | syslog with RFC 3339 timestamps (Lima time, UTC−05:00), for `bastion-01`, `web-01`, `web-02`, `db-01` |
| `samples/<host>/access.log` | nginx combined format (`web-01`; `web-02` also logs `$request_time`) |
| `samples/ground-truth.json` | scenarios with ATT&CK techniques, UTC time ranges, entities and the rules expected to alert |

See `docs/ARCHITECTURE.md` §4.3 for the scenarios. Ingest a file with:

```bash
npm run ingest -- --source linux_auth --host bastion-01 --file samples/bastion-01/auth.log
npm run ingest -- --source nginx_access --host web-01 --file samples/web-01/access.log
```
