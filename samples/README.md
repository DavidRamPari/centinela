# Demo samples

Generated by `packages/loggen` (session S1) and not committed. Regenerate with:

```bash
npm run loggen -- --seed 42 --days 3 --out samples
```

Layout: `samples/<host>/auth.log`, `samples/<host>/access.log` and `samples/ground-truth.json` (scenarios, techniques, time ranges, entities and expected detections). See `docs/ARCHITECTURE.md` §4.3.
