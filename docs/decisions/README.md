# Session decisions

Each build session records the decisions it takes in its own file, `S<N>.md` (for example `S2.md`), numbered `S<N>-01`, `S<N>-02`, and so on, in the format described in `docs/DECISIONS.md`. One file per session keeps parallel branches from conflicting. David folds the important ones into `docs/DECISIONS.md` after merging.
